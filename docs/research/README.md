# Bluetooth microphone research archive

These documents preserve the investigation that led to Agent Remote's
Bluetooth microphone implementation. They are historical engineering records,
not current setup instructions; use the repository README for supported build
and installation steps.

Personal filesystem locations and private diagnostic identifiers have been
replaced with placeholders such as `/path/to/agent-remote` and `/path/to/private-audio-fixtures`.
The recordings themselves are intentionally not part of the repository. See
`Tools/AudioLab/README.md` for reproducible command-line interfaces to the
remaining analysis tools.

# Support

Use GitHub Issues for reproducible bugs and focused feature requests. Include
the Agent Remote version or commit, macOS version, CPU architecture, connection
type, controller revision when known, and whether the optional microphone
driver is installed.

Before filing an issue, run the current `main` build, review `README.md` and
`docs/fleet.md`, and confirm the controller works in macOS. Never attach real
agent transcripts, private audio, credentials, or an unredacted diagnostic
log. Use `SECURITY.md` for vulnerabilities.

The project is maintained on a best-effort basis; no response time or backward-
compatibility guarantee is offered before version 1.0.
